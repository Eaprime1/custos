# Future Forward

*Where repo-hygiene findings land when they aren't a simple fix.*

Companion to [`docs/repo-hygiene-routine.md`](../../docs/repo-hygiene-routine.md).
`tools/repo_hygiene_check.sh` finds missing required documents; the ones
that are a plain copy get ported immediately. The ones that need real
judgment — a `LICENSE` choice, `CODEOWNERS` usernames, a `CLAUDE.md`
tailored to a specific repo's actual environment — land here instead of
being guessed at.

One file per repo: `<repo-name>.md`. Status per item: `OPEN` until judged,
`RESOLVED` with a link once handled. Don't delete rows — same discipline
as the Seed Weir and Artesium Weir logs.
