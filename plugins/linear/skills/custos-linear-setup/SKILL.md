# Custos Linear setup

Read `../custos-seed-intake/references/conventions.md` first.

## Suit and plank labels
The Suit and Plank label groups already exist in team QRU (created 2026-10-09 UTC). Do not recreate them.
1. List labels (with groups) and confirm all nine are present: Seed, Carbonite, Aethereal, Pinnacle; Germ, 1/3 Plank, 2/3 Plank, 3/3 Plank, Crystallized.
2. If one is missing or retired, report it and propose restoring or recreating it; wait for a yes.
3. Linear rejects emoji in label names, so keep the suit emoji in label descriptions.

## Tidying
- Review issues in project Primoris and issues with no project. Report mismatches (status vs plank label, missing Suit or Plank label, missing prima-clock header, duplicates) as a short list and propose fixes. Apply only the fixes the user approves.
- Do not bulk-edit more than a handful of issues without a clear yes.

## Automations
Linear automations live in Linear's settings, so this plugin cannot create them. If asked, suggest candidates (for example moving an issue to In Review when the 3/3 plank label is applied) and say plainly they must be turned on in Linear.
