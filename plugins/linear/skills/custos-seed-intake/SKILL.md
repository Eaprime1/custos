# Custos seed intake

Read `references/conventions.md` first for workspace facts and the issue format.

## Steps
1. Name the seed precisely, using the user's own terminology. Do not substitute generic terms.
2. Assess plank status (Germ, 1/3, 2/3, 3/3, Crystallized) and suit. If unsure, say so and pick the lowest plausible plank rather than inflating it.
3. Search Linear for an existing issue on the same concept (search by key terms) before creating. If one exists, add a comment or update it instead of duplicating.
4. Get the current time and build the prima-clock stamp (YYYYMMDDHHMM, UTC).
5. Apply one Suit label and one Plank label (and keep the header text matching). Create the issue in team QRU, project Primoris unless the user names another, using the title pattern and body header from the conventions file. Set status per the status mapping. Capture what the user said precisely; hold the shape and do not fill in or develop the concept.
6. Record the destination repo if known, otherwise "undetermined".
7. Reply with the issue ID and link plus one line of what was captured.

## Rules
- Hold, don't fill: no speculative expansion of germ-stage seeds.
- Never mark something 3/3 or Pinnacle without the user saying so.
- If the user refers to content you cannot see, say so and ask them to paste or upload it.
