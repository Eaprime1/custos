# Daily review and build loop

One hertz means a reliable sequence of footfalls, not artificially slow work. Run this loop when a session begins or resumes; it is a practice, not a scheduled automation.

| Step | Question | Output |
|---|---|---|
| Orient | What changed in PRs, missions, and source material? | Small relevant inventory |
| Select | Which one bounded task matters now? | Task and non-goals |
| Inspect | What evidence or limits shape it? | Links and unknowns |
| Build | What is the smallest working change? | Artifact or focused draft PR |
| Review | What did checks and human reading reveal? | Findings and questions |
| Handoff | What should the next session know? | Completed step, blocker, next surface |

For a PR, record scope, inspected files/checks, findings, decision needed from Eric, and what belongs in a follow-up rather than scope expansion. Existing PR discussion and review conventions remain the canonical record. Latin terms may appear as **manual PR comments** to clarify intent; consult the working glossary, but do not treat comments as automated or authoritative merge gates.

If the conversation drifts, write: **Detour:** reason. **Return condition:** observable stopping point. Intentional exploration is welcome; unnamed drift is harder to resume after a context reset.

At close, state one completed footfall, one open question, and one next action that needs no full reconstruction.
