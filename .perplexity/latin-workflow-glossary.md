# Latin workflow glossary — working draft

These terms are currently used in **manual PR comments** to clarify review or workflow intent. Eric may use them in messages while we work on GitHub. This document is a memory aid, not a new title convention, label system, automated trigger, CI gate, or approval. Automation can be considered later against actual usage. Source vocabulary: the Latin Workflow Glossary Table shared in this session; confirm exact wording against current PR comments before treating any phrasing as canonical.

| Term | Working cue in a PR conversation |
|---|---|
| Prima Recensio | Initial scan or first verification; state what was actually checked. |
| Extrema Recensio | Deliberately thorough review of risk, edge cases, or root cause. |
| Judicium | A decision is needed from the responsible human; name options and evidence. |
| Novissimum | Rearguard cleanup: loose ends, follow-ups, and closing status. |
| Lustratio | Presentation and coherence pass; polish without changing the underlying decision. |
| Probatio | Verification or sign-off supported by explicit evidence. |
| Ultima Probatio | Final confirmation; never substitutes for Eric's actual PR review. |
| Suprema Lustratio | Exceptionally thorough, inspection-ready presentation pass. |

Modifiers: *prima* = first; *extrema* = furthest/most thorough; *suprema* = highest; *ultima* = final. These are working translations, not claims that a historical Roman procedure exactly matches a software release gate.

Usage: quote the cue in a PR comment, say who is acting and what evidence exists, and leave ordinary GitHub review and merge status untouched. If an existing repository convention uses a term differently, the existing convention takes precedence until Eric resolves the difference.
