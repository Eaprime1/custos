# THE FIVE LAKES VALUATION SYSTEM

Card-based document valuation for the `unexusi-storage` archive — the
exchange-economy foundation for THE/UNEXUS.

Bridged into custos: prima-clock `202606112205`, Blackjack Iteration 21.
See `world/five-lakes.md` for the lake geography and Origin of Hope mythology
this system routes documents into.

## What This Is

Every document in the archive gets exactly one playing card: **suit + rank**.

- **Suit** = which lake it belongs to (see `world/five-lakes.md`)
- **Rank** = its readiness level

The deck stack is the inventory. The number of complete decks is the
archive's depth measure.

## Card Ranks

| Rank | Status | Meaning |
|---|---|---|
| Ace | Sovereign / Pinnacle | Fully crystallized. Spade of Aces = vault sovereign; other suits = pinnacle of their domain. |
| King | Active Stand-alone | Already launched, operating independently. Has its own repo or clear home. |
| Queen | Seed Ready to Launch | Fully formed seed, not yet launched. Needs a push, not more development. |
| Jack | Might Fit / Might Stand Alone | Ambiguous. Good signal, unclear destination. |
| 10 | Ready — Needs Placement | Complete content, no assigned home yet. Waiting for a routing decision. |
| 9 | One Fix Away | Nearly complete. Name the one missing thing and it moves up. |
| 8–6 | Needs Work | Meaningful content, incomplete, multiple gaps. |
| 5–3 | Fragment / Source | Raw material. Incomplete but contains signal worth keeping. Club pool's natural home. |
| 2 | Wild — Non-Separate | Contains something real but doesn't stand alone; part of something larger. |
| Joker | 21st Iteration Badge | Not a rank — a transit marker for direct transfer to unexusi during Blackjack. Added to a card, never replaces it. |

## Currency Anchors

- Base unit: 0.01 cent (USD real-world peg)
- Project currency: 100 monopoly-type dollars per 0.01 cent
- Floor value: 1 chip per document — everything that exists has minimum value
- Physical anchor: Cub Scout uniform (Eric Pace) — first tangible object formally entered as value anchor, vault candidate ♠️

## As-Is Valuation Protocol

1. Count all files in `unexusi-storage`. Each file = 1 chip floor value.
2. Determine the number of complete decks (52 cards/deck). The remainder is 2s and Jokers.
3. Apply the 5-question rubric below to assign a card rank.
4. Assign a suit based on lake destination (`world/five-lakes.md`). Card = suit + rank.
5. Documents earning a Joker go into the direct-transfer queue to unexusi.

## 5-Question Scoring Rubric

| # | Question | Yes | No |
|---|---|---|---|
| 1 | Does it have a clear, meaningful title? | +2 | +0 |
| 2 | Does it have a prima-clock stamp or datable timestamp? | +2 | +0 |
| 3 | Is the content complete rather than fragmentary? | +3 | +0 |
| 4 | Does it connect to or reference other system documents? | +2 | +0 |
| 5 | Is it assigned to a destination repo or lake? | +1 | +0 |

**Score → Rank:** 10 = Ace · 9–8 = King/Queen · 7–6 = Jack/10 · 5–4 = 9/8 · 3–2 = 7/6 · 1 = 5/4/3 · 0 = 2

Questions 1, 2, and 5 are mechanically checkable from file metadata. Questions
3 and 4 require a human (or model) read of the content — the ledger leaves
`card_suit` and `card_rank` as `TBD` until that pass happens.
