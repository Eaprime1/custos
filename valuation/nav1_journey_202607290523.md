# I. INCEPTION STORY

**The instruction.** "Go ahead and add notes if that makes sense and close them.. then let's keep moving on getting branches from the repos completed.. and merged or other. Priority is leaning towards get it done and leave notes or carry forward any thing not resolved."

The fold knew what was needed: a sweep with teeth. Not triage — closure.

**The landscape.** custos carried nine open PRs when this session picked up. tabularium and radix had zero. hodie had been cleared. Within an hour, custos was down to one (the session's own turn log PR), and that too was merged before the session ended. Zero open PRs across all four repos.

**The pattern identified.** Three PRs (#244, #277, #283, and later #287) were squash-merge duplicates — GitHub's squash behavior leaves the source branch alive with original commit SHAs, so new PRs could be opened against already-merged content. The fix: **Settings → General → Automatically delete head branches** — one checkbox, enabled by eaprime1 mid-session. Future squash merges will auto-delete the source branch on close.

**The Codacy pattern.** Three PRs (#246, #282, and initially #279) showed Codacy completing in 0 seconds (`started_at == completed_at`). This is a service-side cached result — not a real analysis. The actual diff content was clean in all cases. The correct call: merge when all other CI checks pass and the diff is clean, noting the cached result explicitly in the PR body.

**The conflict.** One real merge conflict surfaced on `Eaprime1-patch-1` (#279). The branch had a broken DictReader attempt — a dangling `for row in csv.DictReader(...)` inside a `with` block that was still using index-based access below. The fix was to take main's single-loop version of the conflict block. Python syntax validated before push.

**The auto-delete.** Once the repo setting was enabled, the pattern closed. No more ghost branches, no more duplicate PRs.

**The automation conversation.** Near the end of the session, the Shepherd asked what to automate to free nav1 attention for higher-judgment work. The answer crystallized cleanly: automate PR template prefill, branch auto-delete (done), duplicate-PR detection, Codacy cached-result detection, and daily open-PR digest. Keep with nav1: conflict resolution judgment, content/lore review, ethics flags, custody routing, and anything that touches vault or moav without a chain.
