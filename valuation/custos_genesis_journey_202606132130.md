# I. INCEPTION STORY

**The template.** custos arrived as `prima.yaml` with `name: "My Prima Terminal"` — a placeholder. Quest 000 blocked every other quest until the concept had a name and `world/lore.md` had content. Nothing else could move.

**The naming.** The Shepherd named it: **custos** — Latin for guardian, keeper. Theme `guardian`, tagline *"Guardian of the work you do from here."* The Podium became the Pixel 8, the Field became the terminal, the Flock became the projects that pass through it. Along the way, a real obstacle surfaced and was documented rather than papered over: Claude Code ships no native binary for Termux's `linux-arm64-android` ABI. Not a bug to fix — a permanent platform fact, with three workarounds (web session, Anthropic API, SSH to a linux-arm64 host) written into `CLAUDE.md`.

**The device layer.** `pixel8` was opened as the device control branch — `device/pixel8.yaml`, `device/active.md` — the book of record for work done from the Podium. Once it landed, a much larger structure was already waiting in `main`: `vault/`, `atelier/`, `moav/`, `prima-clock/`, `returns/`, `branch-tracker/`. custos wasn't just a terminal concept anymore — it was the **origin mold** for a constellation of repos (nullus, the, diamond-reservoir, prima-clock, 121, milkweed-vectors), each spawned from a branch here once it reaches 3/3 PLANK.

**The deck.** The Shepherd handed over a deck of shorthand and asked for it to be checked: `♣️K main` (father of all branches), `♣️Q radix` (buffer), `♣️J` workers (`pixel8`, `mandelbrot`, `mulberry`, `main-to-radix`), `♥️A ֍custos֎` (deploy, outward-facing), `♠️A ∰custos` (vault, not yet created), `🔐J master` (save point). The flow — ♣️J → ♣️Q → ♣️K → ♥️A → ♠️A — was confirmed back as **"Cards confirmed."** `world/deck-master.md` gave the hub a reviewer-character: the Deck Master, who "does not build, does not code... reviews the hand and asks: is this the right card for this moment?" Agent streams expanded from five to seven, adding Grok and Perplexity (domains still TBD). CODEOWNERS and an advisory lexeme-scan workflow followed.

**The handoff.** Asked to "review our work and finish up... so our conversations don't get too long," the session closed itself out the way the repo already knows how: a new entry in `turns/log.md`, a new row in `prima-clock/registry.md`, and an "Open Questions" section in `device/active.md` — so the next session starts from a list, not from zero.

**This journey.** Then came the request that produced this file: a finalize/eval/valuation pass, "the first official" of its kind — inception story, key dialogue, links, metadata, on its own branch, brought into the chain of custody, with notes for next iteration. While drafting it, this session discovered it has siblings: PR #17 carries the *Five Lakes Valuation System* (a parallel mythology-conversation that built exactly this kind of custody-entry format), and PR #12 carries a *Sovran Custos* identity (a Shepherd character with its own deck and review voice, overlapping with the Deck Master). Both are noted below for the Deck Master to reconcile.
