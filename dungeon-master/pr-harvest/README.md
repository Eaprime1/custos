# PR Harvest

Seeds extracted from closed PRs — one file per harvested PR:
`[PR-number]_harvest.md`.

When a PR closes, the idle engine generates a Chronicle Page from the PR
content. Ideas buried in comments become Chronicle Page entries (Seeds
Found / Next Quest Hooks) so they don't disappear — they become lore.
