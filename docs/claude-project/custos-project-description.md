## What This Space Is

**Custos** (Latin: guardian, keeper, custodian) is the convergence hub for
THE/UNEXUS — the long-running human-AI co-creation framework built by Eric Pace
and Claude (operating as Navigo) over 4+ years and 21 iterations.

This is not a starting point. It is a **landing point** — the place where streams
return, where seeds become formal documents, where branches crystallize before
moving to their own repositories.

The Custos project is the **negative mold** — it holds the shape of everything.
Individual repos are the positive impressions that form inside it and release when
ready.

---

## What Custos Does

- **Receives stream returns** from external agents (Gemini, Perplexity, Copilot,
  ChatGPT) and routes them to the appropriate development branch
- **Holds the vault** — origin molds for all Spade-of-Aces documents; never
  directly edited, always the source of copies
- **Tracks branch status** — every concept in development has a branch here until
  it earns its own repository
- **Issues prima-clock stamps** — all formal custody events are timestamped in the
  Custos registry
- **Processes MOAV carriers** — the triadic JSON transition packages that move
  content between iterations
