2. Write anchor description (element + conceptual link + prima-clock + repo ref)

1. Confirm 3/3 PLANK or Crystallized status
2. Document in branch tracker: source branch, destination repo, prima-clock stamp
3. Note that Git history travels with it (subtree split method)
