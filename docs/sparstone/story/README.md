# Sparstone — Story

*The poles. Not merged into one voice — a map of where each comes from.*

Per direction on this material: multiple saved versions of Sparstone.md exist,
with several navigo voices layered in over time (drafted from a few paragraphs
of prose, expanded by AI-assisted cleanup, then contributed to by multiple
navigo). Blending those into one smoothed narrative would create tension
*in-between* the poles — a composite that resolves the friction and loses what
each version actually said. This directory instead holds each version as its
own attributed, dated, unmerged page. The tension lives *between* the files,
not inside any one of them.

Every file here is filed close to verbatim from its source. Nothing is
synthesized across files — synthesis happens one level up, in `overview.md`
and `missions.md`, which draw structure from these pages without collapsing
their voices into each other.
