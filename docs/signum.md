# Signum

`prima-clock: 202610311130` (UTC)
`status: official name, vocabulary only. Nothing is built.`
Decided by the Shepherd in a review comment on custos#503, 202610311021 UTC: "signum is excellent lets make it official."

**Signum** (Latin: a sign, a mark, a seal; also a military standard) is the project's name for its marks: the records that say what was checked about a piece of work, and by whom. It is the umbrella name chosen in `.artesian/makers-mark-navigo5-turn2.md` (v0.1) and made official here. The individual parts keep their plain English names.

A mark is a **record**, not a call. No Latin cue sets one, and no mark seals, merges or approves anything. Only the Shepherd gives the seal cue and the merge word.

Grounding the word in a citable source is still open, as for any lexeme (`docs/issue-system.md`, the lexeme process).

## The marks

| Mark | Says | Who or what can give it |
|---|---|---|
| **Quill** | Provenance: where this came from and who carried it | Anyone who carried it, naming themselves |
| **Claim Mark** | Occupancy: this work is taken | The claimant |
| **Validation Mark** | Named checks were run and passed | A script or a person, saying which checks |
| **Witness Mark** | Someone read it, and says so | Anyone who has read the document (see below) |
| **Integrity Mark** | The same bytes as when sealed (a hash) | A script. The first one is in `.gemini/feed/…receipt.md` |
| **Reference Mark** | The document was intentionally referenced | Logged when it happens. Not built |

Provenance is not authorship. Authorship is not validation. Validation is not ethical review. Ethical review is not integrity. Integrity is not valuation. A mark may state only what its witness actually did, and nothing may say "certified" for a step nobody did.

"UL-style" describes the idea (someone other than the maker checks before it ships). It is not a name. "UL Listed" is not used for any project mark, as two earlier reviews asked.

## Witnessing (the Shepherd's rule, 202610311056 UTC)

In his words from the review: anyone can add a witness. If you read the document you have witnessed it, and you may add your witness mark, or a counter to an existing witness mark, within reason. Skimming a document to find something is not a witness; it is a **reference**, and the project will log it when the document is intentionally referenced. The Shepherd's own witness is required because he is currently the only human navigo. This is part of a safe creative space, inside safe bookends, in a safe environment.

Reading, not the Shepherd's rule: a witness mark should say which document and which version (a head commit or a hash), and whether it was read in full. That is a proposal.
