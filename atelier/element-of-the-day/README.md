# Element of the day — atelier seed

A small, repeatable learning and research practice: focus on one chemical element per day in ascending atomic-number order, beginning with hydrogen when the first run is actually recorded. After the last confirmed element, return to hydrogen. A separate optional news lane can surface new research on *any* element without changing the core sequence.

This is a manual atelier experiment, not an active scheduled task, feed subscription, or promise of a daily automatic post. Keep `state.md` as the human-readable cursor and use `entry-template.md` for each completed entry. Do not infer the next element from the calendar if a day is missed: advance the cursor once per completed core entry. Do not backfill a skipped day with invented research.

## Daily footfall

1. Read `state.md` to find the next atomic number; if unset, begin with 1 (hydrogen). Check if today's entry already exists to prevent duplicate turns.
2. Verify element name, symbol, atomic number, and scientific baseline against a reliable reference; distinguish elemental facts from properties of compounds and isotopes.
3. Write a compact portrait: what it is, a distinctive property, a use or scientific question, and one visual/educational hook. State uncertainty explicitly.
4. Optional news lane: search dated scientific articles or papers; distinguish publication date from event date; link original research and corroborating coverage where possible. No relevant new item is a valid result. News on another element is a side note, not a replacement for the scheduled element.
5. Record source links, access date, evidence level, and any correction needed. Update the cursor only after the core portrait is complete and reviewed.

Suggested paths: `entries/YYYY-MM-DD-ZZZ-symbol.md` for dated entries, with `ZZZ` as three-digit atomic number. Keep the original source of a Drive item linked rather than bulk copying it. If a series later needs code, external data, or visualizations, consider the existing `eaprime1/121` periodic-table expansion project and link its canonical material rather than duplicating it.

## Guardrails

- This repository is public: check permissions before importing Drive text or images; prefer citations and source links.
- A publication published today is not necessarily a discovery made today. Avoid overstating speculative element claims or conflating isotopes with elements.
- No automatic paid API calls, daily Actions job, or unsolicited PR/comment per element in this seed. Pilot several manual entries before choosing automation or a publishing schedule.
- This folder is an atelier intake, not a definitive chemistry database.
