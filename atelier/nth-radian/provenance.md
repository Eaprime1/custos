# Provenance Boundaries — Nth Radian / Prima Wobble

**Status:** Germ support document  
**Purpose:** Keep source, model, and narrative connected without collapsing them.

## Layer A — sourced physical fact or scientific analogy

Use for externally verifiable material: physics, cosmology, history, language, measurements, or quotations.

Required:

- source title and link;
- date accessed;
- what the source actually supports;
- any uncertainty or disagreement;
- `null_copy: true` when the project retains information while the source retains the original.

A source is evidence only for the claim it directly supports.

## Layer B — project hypothesis or functional model

Use when the project proposes a mechanism that could guide design, mathematics, workflow, or testing.

Examples:

- an Nth Radian converts a closed loop into a new trajectory;
- “else” represents degrees of freedom rather than only another menu option;
- a Wobble Record helps plans recognize related prior movement.

A model may be useful before it is scientifically established. Its status must remain visible.

## Layer C — project cosmology or narrative

Use for foundational world-language and meaning:

- Conatus Primus;
- the first Nth Radian;
- Prima Wobble;
- concept-time crystallization;
- the universal background as retained trace;
- witness emerging through first difference.

These may carry truth, usefulness, and gravity within the project without being presented as measurements of the physical universe.

## Interpretation bridge

A single artifact may connect all three layers, but each passage or claim should identify its layer.

```yaml
provenance:
  layer: physical_fact | scientific_analogy | project_hypothesis | project_cosmology
  source_relation: origin | null_copy | interpretation | transformation
  sources: []
  uncertainties: []
```

## Latin note

`conatus` supports the senses effort, attempt, striving, and impulse. **Conatus Primus** uses masculine agreement for “first striving.” If **Conatus Prima** becomes an intentional project name, record it as a project lexeme rather than silently treating it as classical agreement.

## Null Copy

A Null Copy preserves an honest external relationship:

- the source retains its original;
- Custos records what was received;
- extracted fact remains distinguishable from project interpretation;
- narrative transformation receives its own authorship and custody;
- no later polish is allowed to erase the source boundary.
