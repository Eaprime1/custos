## The sequence

> **Conatus supplies pressure.  
> The Nth Radian supplies direction.  
> The Prima Wobble supplies difference.  
> Witness supplies relationship.  
> Concept-time supplies persistence.**

1. **Conatus Primus** — the first striving, effort, impulse, or pressure toward differentiation.
2. **The first Nth Radian** — the smallest available deviation opened by that striving. It is not the wobble; it makes wobble possible.
3. **Prima Wobble** — the first observable result. Symmetry no longer closes perfectly. Recurrence can become trajectory.
4. **Witness / observation** — the difference enters relationship and can become recordable.
5. **Concept-time crystallization** — distinctions can persist, be compared, named, related, and remembered.
6. **Universal background** — within project cosmology, the retained trace seeded by the Prima Wobble.

## Language note

`conatus` is Latin for an effort, attempt, striving, or impulse. Because the noun is masculine, **Conatus Primus** is the grammatical form for "first striving." **Prima Wobble** remains the project's hybrid name for the first result.

**Conatus Prima** may still be used deliberately as a project lexeme if later ratified; it should then be marked as project usage rather than presented as classical Latin.

## Distinctions that must hold

- **Nth Radian is cause or opening; wobble is result.**
- **Effort precedes observable difference.**
- **Concept-time is not automatically chronological time.**
- **Witness and observation may not be identical.** A witness can retain relationship or testimony; an observation may only register difference.
- **Universal background is project cosmology here.** It is not automatically a scientific claim about the measured cosmic microwave background.
- **Null Copy preserves an originating state or source relation.** It does not prove that a proposed physical event occurred.
- **Icon recurrence creates a semantic address, not automatic equivalence.** Every appearance can point toward the same concept while retaining its local context.

## The open paradox

Did a witness already need to exist for the Prima Wobble to become observable?

Or did the first difference create the possibility of observation—and therefore its own first witness?

The record must preserve multiple witness roles without forcing a premature answer:

- `constitutive` — witnessing participates in bringing concept-time into existence
- `evidentiary` — witnessing records a wobble that already occurred
- `interpretive` — witnessing gives the wobble meaning
- `latent` — capacity to witness exists but has not resolved
- `unknown` — intentionally held open
