## Who this is for

The Mulberry Initialization named five roles that custos hasn't built: **Commissioner, Artesian, Quartermaster, Herald, Broker**. `world/unoiam-lifecycle.md` carries that list forward as "tracked but not built." This document is written *to* the first of those — the Commissioner — before it exists, the way a letter gets written to someone you're expecting rather than someone who's arrived.

A Commissioner's job, as the name implies, is to hand out commissions: frame the question well enough that a contributor (human or AI) can pick it up cold and produce something real. custos already does this by hand — `atelier/commissions/deep-dive-sheep.md`, `john10-auth.md`, and `luke15-lost.md` are three examples written before the role had a name. This document is the spread: everything currently available to commission, organized so a Commissioner (or anyone acting as one) can choose work rather than invent it.

## What should exist but doesn't yet

Flagging these here so the Commissioner (or whoever stands in for one) has a map of the holes, not just the filled squares:

- **The Commissioner / Artesian / Quartermaster / Herald / Broker roles themselves.** Named once in the Mulberry Initialization, repeated in `world/unoiam-lifecycle.md`, never defined. `world/deck-master.md` is the closest precedent for what a fully-written role document looks like in this repo — same shape would work here.
- **The Ka-Coin economic layer / Five Lakes Rubric's scoring mechanics.** Referenced in `valuation/five_lakes_valuation_bridge_202606112205.md` and the Mulberry thread, never built out as a usable system.
- **`beasis`.** Coined mid-conversation ("to be as is" — no resolution required before you're allowed to exist), already cross-referenced in `world/unoiam-lifecycle.md`'s etymology of Unoiam, flagged as an open TODO in `docs/custos-plan.md` line 84 ("Consider whether beasis concept connects to or extends custos"). Has never had its own seed file.
- **The card-math name.** `J - 21 = A`, `J + A = 21` — the arithmetic underneath J-21 (`world/symbols.md`) — was asked to be named in `incoming/pre-nullus/202606210052_J21-Lumenar-growth-observation.md` (open item 1). Still unnamed.
- **"Suxen" and "nexus."** Proposed as a role-pair name for how eaprime1 and Claude trade positions in conversation. Not yet formalized as lexemes or folded into `world/symbols.md`.
- **The "zero point state interaction with the universe."** Distinguished explicitly from zero-point energy, described as what remains when everything circumstantial is removed. Conceptually near `incoming/pre-nullus/README.md`'s nullification process but deliberately kept separate. No home yet in `world/lore.md`.
- **The House of Confusion as a working tool.** A real bash implementation exists (the `the_beacon` / `monkey_check` / `exit_routing` BBS router, uploaded this session) but hasn't been placed anywhere in the repo as a runnable script. It's the literal mechanics behind the lore in `world/unoiam-lifecycle.md`'s Phase 0.
- **A Seneschal lore file proper.** `world/unoiam-lifecycle.md` describes Seneschal *functions* in passing — atmospheric pressure, audit tags, dispatching the Shadow Peers — but there's no dedicated document the way `world/deck-master.md` exists for the Deck Master. See the new commission for this.
