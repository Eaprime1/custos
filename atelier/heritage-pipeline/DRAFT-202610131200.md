## 3. Engine tests (verified 202610131200, run on a text extract of the 86-page Sanctum PDF)

| Finding | Evidence |
|---|---|
| The collapse engine's own output fails the makers engine's check. | `conversation_collapse_engine.py collapse` then `makers_mark_engine.py verify` on the PR Journey gives **TAMPERED**: recorded `b5f03098aa`, expected `c5a866752d`. |
| Cause: the two engines normalize text differently. | The makers cleaner reads the `---` rules in the body as YAML front matter and removes the text between them (2124 characters become 1452). The collapse engine hashes the body with a plain `strip()`. |
| TKP cannot tell texts apart at the top. | The Sanctum text scores **0.99** (the clamp). A plain paragraph scores 0.50 (the floor). The 0.75 gate passes any text with enough headings and symbols. |
| Automatic seeds missed the real ones. | The engine returned five seeds, all chamber descriptions. None is `suxens_stone`, `shadow_road_pressure` or `return_to_prime`. The SOP asks for 1-3, hand-picked. |
| Seed timestamps are processing time. | `timestamp_utc` is the engine's run time, not when the conversation happened. |
| The journey text claims things that were not done. | Generated lines say monitoring is active, withdrawal is engaged, and findings were "harvested into ... permanent storage." |
| Title and ID are rough. | The title came out as `## I. Transition from Discovery to Heritage`; the ID comes from the file name. |

Repro, from a scratch folder: copy both engines, run `python3 -I conversation_collapse_engine.py collapse <text> -o out`, then `python3 -I makers_mark_engine.py verify out/<id>_PR_Journey.md`.
