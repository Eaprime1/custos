# Ready for Final Merge Review — Scene Checklist

Prima-clock: 202610070820

A scene PR creator brings the PR to this state, then says so in the PR. The
Shepherd reviews from there. Creators never seal or merge.

## Checklist

- [ ] Not a draft.
- [ ] Checks green for the PR's base. A stacked PR runs fewer checks; say so in the description.
- [ ] Every review thread answered, then resolved or deferred with a reason.
- [ ] PR description filled in: Intent, What Arrived, Resonance, Ethics Check, Sense Check, What Door.
- [ ] No outstanding requested changes.
- [ ] `bash tools/scan_lexeme.sh` run, results noted.
- [ ] Privacy scan: no private details, no real-place names.
- [ ] Scene filed from the [scene template](../scene-template.md) with a Conversation ID.
- [ ] [Extended Wobble Record](../wobble-record-template.md) filed or linked.
- [ ] At least one recognition hook offered; hook answers noted.
- [ ] Anchor status stated for every anchor.
- [ ] Row added to [INDEX.md](INDEX.md).
- [ ] Prima-clock stamp on every new `.md` file.
- [ ] Final-review note in the PR: what is done, what is deferred.

## Not the creator's

Sealing (the owner's cue) and merging stay with the Shepherd. A navigo
describes the seal cue in words and does not post it.
