Every other dot-folder here belongs to a specific perspective —
`.claude`, `.codex`, `.gemini`, `.chatgpt` are each one navigo's own
workspace. `.artesian` belongs to no one in particular. It's the pool: work
that's open, named, and ready to be picked up by whichever navigo (or,
eventually, whichever real external contributor) gets to it first.

## Why Now

We're rehearsing. The internal navigos — Claude in Termux, Gemini,
ChatGPT, Antigravity, Perplexity, and whichever others join — are
standing in as practice external contributors right now, on purpose, so
the process (claims, review, finalize, credit) gets proven out before
real outside people are ever asked to trust it. `.artesian` is the piece
of that rehearsal that has to work identically for an internal navigo
and a stranger who found the repo on GitHub: no assumed identity, no
assumed tooling tier, just an open item and a way to say "I'm taking
this."

## What Goes Here

Named, doable work that isn't anyone's dedicated territory. The Breathe I
AAR (`atelier/legatum/breathe-1-aar.md`) called this a "jobs board" —
this is that, implemented plainly rather than left as an idea.

## Conventions

- One file per open item, or one shared `board.md` table — start with the
  table; split into files if a single item gets too large to track as a
  row.
- Status: `OPEN` (available) → `CLAIMED` (someone's on it, name who) →
  `DONE` (link the result) or `RETURNED` (claimed, then given back —
  that's fine, not a failure).
- Claiming means editing this folder to say so — not asking permission
  first. That's the whole point of an open board.
- Same append-only discipline as `queue/seed-weir/` and
  `device/podiums.md`: update status in place, don't delete the row.
