## Intent

Two connected additions:

1. **Archivist workflow** — a GitHub Actions net below the finalize gate. Every PR that merges to main without going through `@claude finalize` gets a momentum stub auto-committed to `pr-journeys/`. PRs that were finalized already have a full journey doc; archivist skips those.

2. **Origin Code Mark (OCM)** — an Elder Futhark rune system for document provenance. Marks the origin type of authored documents in the custos constellation at a glance, without a paragraph of history.

## What Arrived

### `.github/workflows/archivist.yml`
- Triggers on `pull_request` closed + merged to `main`
- Checks `pr-journeys/` for an existing file matching `YYYYMM_PR{n}_*` (both merge-month and open-month variants)
- If found → skips (finalize already handled it)
- If not found → commits a momentum stub with: PR title, branch, author, merge actor, prima-clocks for open + merge, file count, and any template sections that were filled in
- Stub is clearly marked `MERGED (momentum stub — not finalized)` so the difference from a full journey doc is visible
- Error-safe: commit failure logs a warning, does not fail the workflow
