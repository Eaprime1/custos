Record the Shepherd's observation comments when they are made, so they are not left to be remembered and written up afterwards. The Shepherd asked for a draft PR with a test, using their existing marker: `shepherd observation` and then the date and time.

## What Arrived

A workflow, `observation-log.yml`, that watches reviews, review comments and PR comments from the owner for `shepherd observation` at the start of a line (optionally followed by a 12-digit stamp, e.g. `shepherd observation 202610171524`) and records each in **one living comment** on the PR:

- the time GitHub posted it (UTC) and the stamp **as typed**, side by side. The Shepherd's stamps have been Pacific; the repo's records are UTC. Nothing converts one to the other.
- who, the commit, and the first 240 characters; a review's inline comments are counted and linked.
- an edit updates its row; a deletion leaves the row in place.
- skipped: quoted text, code, comments with the Claude Code footer (a navigo under the owner's login), bots, and anyone but the owner.
