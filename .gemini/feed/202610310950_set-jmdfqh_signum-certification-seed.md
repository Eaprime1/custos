## Reading (mine, not his)

- "UL-style" describes the idea, not the name. The project already chose **Signum**, and two reviews asked that "UL Listed" not be used. This seed uses Signum as the working name and keeps "UL-style" for talk only.
- A mark is only as strong as its witness. Each mark in the passport should say what kind of witness gave it: a script, a person, an AI, or the maker. The Navigo5 note already says "the mark should never imply more authority than the witness actually has".
- The system is a ladder of separate claims, not one stamp:
  1. **Integrity**: the same bytes as when sealed (a hash). A script can give this.
  2. **Validation**: named checks were run and passed (for example the repo's own tests). A script can give this.
  3. **Witness**: who or what looked, and what kind of witness it was.
  4. **Ethical review**: a person's judgment. Never a script's.
  5. **Valuation**: kept apart and simulation-only unless the Shepherd authorizes otherwise.
- Nothing may say "certified" for a step nobody did.
