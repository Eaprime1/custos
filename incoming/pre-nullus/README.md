# PRE-NULLUS

A pre-nullus event: something arrives at custos before the system has
a settled name or place for it — the moment before the "null" state
resolves into a custody category.

First case: PR #38 (bounty Issue #35), the project's first unsolicited
external contribution. Since the event originated *in* custos itself,
intake was custos receiving from itself — a degenerate but valid case
that establishes this pattern for future repos.
